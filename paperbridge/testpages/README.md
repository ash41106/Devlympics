# Real handwritten test pages

1. Open `http://localhost:3000/register.html` and print 3 copies (A4).
2. Three **different people** each handwrite one page below. Blue/black ballpoint, natural speed, small mistakes and cuts are good, they make it real.
3. Photograph each page flat, daylight, filling the frame. Save here as `page1.jpg`, `page2.jpg`, `page3.jpg`.
4. Copy the matching answer key below into `page1.json` etc. (the `.json` files are already here).
5. Start the server with your key, then run `node tools/eval.js`. Open `eval-report.html`.

Photos and reports are git-ignored: they never go to GitHub.
